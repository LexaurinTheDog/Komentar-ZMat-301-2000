# Komentář k zákonu č. 301/2000 Sb., o matrikách, jménu a příjmení a o změně některých souvisejících zákonů

Otevřený komentář k zákonu o matrikách, jménu a příjmení — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; matriční úřady a matrikáři, matriční knihy, zápisy narození, manželství, partnerství a úmrtí, matriční doklady, doklady k uzavření manželství, zvláštní matrika, jméno a příjmení, tvar příjmení, změna jména a příjmení a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2000-00301_2025-01-01`.
